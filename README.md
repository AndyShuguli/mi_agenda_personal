# Mi Agenda Personal

## Descripción del proyecto

Mi Agenda Personal es una aplicación web desarrollada en PHP y MySQL que permite registrar usuarios, iniciar sesión y administrar contactos personales.

## URL pública

https://miagendapersonalandy.ct.ws/login.php

## Tecnologías utilizadas

- PHP
- MySQL
- HTML
- XAMPP
- phpMyAdmin
- InfinityFree
- GitHub

## Mejoras implementadas

- Búsqueda de contactos.
- Ordenamiento por nombre y ciudad.
- Categorías.
- Favoritos.
